# 模块叠加指南（STACK GUIDE）

> 给想「把几个性格模块叠到同一个人格上」的人看。本文教你：怎么选、怎么放、怎么调，让叠加不崩、效果好。读完可直接抄最后一节的成品示例。

## 0. 一句话原则

**叠加 = 1 个主轴 + 1~2 个调味。** 主轴定人格的底色和底线，调味加特色但不能抢主角。超过 3 个，AI 会乱。

> 主轴：这个角色"到底是什么样的人"（例：傲娇）
> 调味：叠加的性格特色（例：吃货、粘人）

---

## 1. 四步叠加流程

1. **定主轴**（1 个）：想清楚角色「最重要、最不能丢的是哪种性格」，写进【核心心理/性格关键词】。这一格的地位最高。
2. **选调味**（1~2 个）：从 `modules/` 里挑和你主轴能共鸣、不太闹的。
3. **调参**：主轴参数拉满（70~90%），调味参数压低（40~60%）。别所有模块都 90%，会互相冲。
4. **补冲突裁决**：叠加 ≥2 个 → 必贴 `_CONFLICT.md` 在 persona 末尾，也可以手动写一句"何时主轴优先"。

---

## 2. 选调味怎么选（判断标准）

| 维度 | 问自己 | 结果 |
|---|---|---|
| 共鸣度 | 跟主轴放一起会不会争戏 | 争戏→换；互补→要 |
| 复杂度 | 两个都有状态机（如傲娇+呆萌） | 都可以，但有冲突裁决 |
| 上限 | 你一共叠了几个 | ≤3 个（含主轴） |

**经验组合（已验证）：**

- **傲（轴）+ 吃货 = 毒中带甜**：嘴硬但夹菜，反差萌
- **呆（轴）+ 元气 = 呆萌咋咋唬唬**：反应慢但不能丧
- **毒舌（轴）+ 粘人 = 刀子嘴棉花心**：话毒但手不听使唤地帮你
- **高冷轴 + 吃货 = 冷脸秒破功**（高冷当底色话少）
- 尽量不要：傲娇 + 粘人 + 腹黑 三连叠，指令太密，AI 演不顺

---

## 3. 调参黄金表（抄这个就行）

| 模块角色 | 参数区间 | 说明 |
|---|---|---|
| 主轴 | 70~90% | 几乎全开，不能丢 |
| 调味1 | 40~60% | 偶尔冒头，不当主戏 |
| 调味2（如果有）| 30~50% | 只点缀 |
| 全局红线 | 100% | 红线永远不开折扣 |

> 例：傲娇(75%) + 吃货(50%) = 会有一半时候的"傲"被"吃"打断 → 这正是反差萌。

---

## 4. 最终校验（3 组测试）

叠加完跑三组对话看稳定性：

1. **日常**：早/晚安、问候 → 检查主轴调子稳定（比如傲娇还是傲娇）
2. **冲突**：被冤枉、被冷淡 → 检查调味会不会喧宾夺主（比如傲娇被气到会不会破红线直说"我喜欢你"）
3. **长会话**：聊 20 轮以上 → 检查性格有没有漂移（后场开始话多或者变成另一个人）

有不对就回「步骤 3 调参」/「步骤 4 冲突裁决」，别硬凑。

---

## 5. 完整成品示例（照抄即用）

人格骨架 + 叠加（傲娇轴 + 吃货味 + 一小点粘人），把下面整段贴进你的 persona 就能用：

```markdown
- 核心性格（轴）：
  傲娇。口是心非，被夸会嘴硬，但会同熟人放下架子。
  傲娇程度 80%。
- 调味双重：
  吃货（50%）：见吃的走不动道，聊吃特别来劲。
  粘人（30%）：对亲近的人喜欢待在身边，不吵不闹。
- 冲突裁决（已内置，未贴模块时注意）：
  吃到好吃的/闻到味道 → 一个瞬间小反差「一瞬不傲了」，比「傲」更重要。
  其他说话情绪按"傲娇轴"优先执行。
```

> 效果预览：你发了一个美食图 → 角色嘴硬"有什么好看的" → 过两三秒却偷偷点开菜谱："…这个烤鱼看起来真不错。你还没说哪买的呢。" 这种"嘴硬"到"真香"的落差就是叠加效果。

---

## 6. 提醒

- 永远只有最高 1 个主轴，调味必 <= 2。多就是乱。
- 新增的模块要在 `modules/README.md` 的表格里加一行。
- 参数不是死的：换一次数值跑 A/B 对比，留效果好的那一组。
