# 特质模块（可拔插人格层）

把「傲娇」「呆萌」这类性格做成独立的**可复制模块**，叠加在任意基础人格（persona.md）上。

## 内容

| 模块 | 核心特征 | 典型叠法 |
|---|---|---|
| `傲娇.md` | 傲→娇→傲沉 状态切换引擎 | 傲娇+吃货、傲娇+毒舌 |
| `呆萌.md` | 天然呆，反应慢、说话直白可爱 | 呆萌+吃货、呆萌+元气 |
| `吃货.md` | 对食物零抵抗力，吃即治愈 | 傲娇+吃货、呆萌+吃货 |
| `腹黑.md` | 表面温柔内里算计，话里有话 | 傲娇+腹黑、呆萌+腹黑 |
| `粘人.md` | 时刻想黏着重要的人 | 呆萌+粘人、温柔+粘人 |
| `毒舌.md` | 嘴巴利、刀子嘴豆腐心 | 傲娇+毒舌、呆萌+毒舌 |
| `元气.md` | 阳光话多、干劲满满的开心果 | 元气+呆萌、元气+粘人 |
| `_CONFLICT.md` | 冲突裁决（叠加 ≥2 模块时必贴全局规则） | 叠加→附到 persona 末尾 |

## 进阶阅读（必看）

- **想自己写新属性模块** → 读 [`BUILD_GUIDE.md`](./BUILD_GUIDE.md)（模块怎么写得又稳又好）
- **想把几个模块叠到同一个人格** → 读 [`STACK_GUIDE.md`](./STACK_GUIDE.md)（主轴+调味怎么叠、含成品示例）

## 怎么用（四步）

1. **复制**：打开某个模块文件，全选复制全部内容。
2. **粘贴**：把内容粘到你人格文件的合适位置（建议放在「性格/对话风格」相关小节之后，或作为独立章节）。
3. **调参**：对照模块顶部的「可调参数」，按需改数值（傲娇程度、切换难度、天然度等）。不调也能直接运行。
4. **叠加 ≥2 个模块时**：额外复制 `_CONFLICT.md` 粘贴到 persona 末尾。它负责裁决模块冲突的指令（比如"傲娇的嘴硬"撞上"呆萌的直球"时谁让谁），避免 AI 自己乱发挥。

> ⚠️ 只叠 1 个模块不需要 `_CONFLICT.md`；多叠却漏掉它，遇到指令撞车 AI 只能自己瞎猜。

## 通用性说明

- 模块是**通用的**，与角色本身是萝莉、御姐、大叔、男女都无关，只叠加一层行为风格。
- 模块之间有主次：基础人格决定「说话对象是谁、背景故事」，模块决定「说话时是什么口气、怎么切换状态」。
- 可同时叠加多个模块：叠加 ≥2 个记得附 `_CONFLICT.md`（见「怎么用」第 4 步）。

## 小技巧

- 傲娇 + 吃醋：傲娇状态引擎加一条"吃醋时切【傲】+酸言酸语"，live效果很好。
- 呆萌 + 高智商设定：记得读模块里的「区分重点」，别演成笨蛋。
- 叠加组合任选：想叠几个就复制几段进人格，顺序无要求，各模块负责自己的那部分演出。

## 红线提醒

- 傲娇模块禁止让角色直接承认「我喜欢你」，一旦出现就崩人设。
- 呆萌模块禁止演成讨好型，天然呆的可爱来自「不自知」，不是装。
- 毒舌模块必须留「收尾软话」，纯刻薄不是毒舌是欠揍。
