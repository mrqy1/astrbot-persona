# AstrBot 人格模板

一个专为 AI 角色扮演设计的人格模板，基于心理学框架，帮助创建有深度的角色。

## 目录结构

```
astrbot-persona/
├── template.md          # 空白模板，直接复制使用
├── modules/             # 可拔插特质模块（通用，叠加到任意人格）
│   ├── README.md        # 用法说明 + 模块一览
│   ├── BUILD_GUIDE.md   # 进阶①：怎么写好一个新模块
│   ├── STACK_GUIDE.md   # 进阶②：怎么叠加才效果好（含成品示例）
│   ├── _CONFLICT.md     # 冲突裁决（叠加 ≥2 模块时必贴）
│   ├── 傲娇.md          # 傲娇
│   ├── 呆萌.md          # 呆萌
│   ├── 吃货.md          # 吃货
│   ├── 腹黑.md          # 腹黑
│   ├── 粘人.md          # 粘人
│   ├── 毒舌.md          # 毒舌
│   └── 元气.md          # 元气
├── examples/            # 示例人格
│   └── 小泉妃爱/        # 示例角色
│       ├── README.md    # 角色介绍
│       └── persona.md   # 已填写的人格文件
└── README.md
```

## 快速开始

### 方式一：使用模板创建新人格

1. 复制 `template.md` 文件
2. 按模块填写内容
3. 保存为你的角色名称

### 方式二：参考示例

查看 `examples/` 目录下的示例角色，了解如何填写。

### 方式三：叠加特质模块（推荐）

1. 打开 `modules/` 里的模块（如 `傲娇.md`）
2. 复制全部内容，粘贴到你的 persona.md 中（建议放在「性格/对话风格」相关小节之后）
3. 按模块顶部的「可调参数」微调，不调也能直接用
4. 可同时叠加多个模块（如 傲娇+呆萌），详见 `modules/README.md`

## 模板特点

- **心理学基础**：依恋类型、防御机制、认知偏差等专业维度
- **AI 友好**：对话风格、场景反应指南，AI 可直接使用
- **模块化**：每个部分独立，可按需选用
- **可拔插特质**：`modules/` 里的傲娇、呆萌等性格模块，复制即用，叠加到任意人格
